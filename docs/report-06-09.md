## 1. Ролер і лог кидків — найбільша поверхня змін

### 1.1 Один кидок = одна дія (`RollSpec`)
Раніше атака приїжджала у ролер двома викликами (кидок влучання, потім шкода), і **лейбл другого
викидався**. Тепер запит один: назва + d20-тест + частини шкоди + нотатка + скільки інстансів.

- [ ] Shift-клік по атаці → у лотку є **і** тест, **і** шкода, з правильною назвою.
- [ ] Закляття без кидка влучання (Fireball-подібне) прилітає як «кількість без вердикту» — немає
      тумблера переваги й немає рядка влучання.
- [ ] **Волея** (Eldritch Blast, кілька променів) з лотка: `times` тепер належить дії, тож
      damage-only закляття теж може прилетіти волеєю.

### 1.2 Волея лишається однією дією після перезавантаження
- [ ] Кинь Eldritch Blast на 2–3 промені → у лозі це **один блок ×N**, а не N незалежних рядків.
- [ ] **Перезавантаж сторінку** → блок лишається блоком (раніше розсипався на окремі кидки).
- ⚠ Кожен кидок усередині блоку має власні контроли (перевага / перекид) — перевір, що вони діють
      на «свій» рядок, а не на перший.

### 1.3 Виправлення після ревʼю хвилі (шість дефектів)
- [ ] **Складений токен**: набери в лотку `2d6+3`, потім наступний токен — каретка має стояти
      **після** обох пілюль. Баг був: `2d6+3 fire 1d6 cold` кидав `+3` як **cold**.
- [ ] **Поправка переваги**: кидок, зроблений під ефектом з перевагою, при циклі переваги записує
      `from` = реальний режим (не `neither`); повернення в початковий режим **прибирає** поправку.
- [ ] **Перезавантаження**: кидок із іменованим модифікатором (Bless +2) після рестарту досі
      показує, звідки він (`modParts` більше не губиться).
- [ ] Кнопка «кинути» на damage-only специфікації більше не «нічого не робить».
- [ ] Бейдж ×N більше не наїжджає на лейбл першого рядка (було 8.6 px).

### 1.4 Пілюлі памʼятають, звідки взялись
- [ ] Наведи на кістку в лозі → підказка називає **джерело** (Bless d4 vs кістка, яку ти дописав
      руками) — раніше це було одне й те саме.
- [ ] Наведи на плоский модифікатор → перелічує частини, з яких він складений.
- [ ] Пілюля `note` (текст без числа) більше **не** потрапляє у суму — вона їде в нотатку кидка.

### 1.5 Формула каже, чого не змогла прочитати
- [ ] Зроби homebrew-зброю з кривим `damage` (наприклад `1d8 + ??? slashing`) → у рядку атаки має
      зʼявитись нотатка «не прочитано: …», і те саме в нотатці кидка.
- [ ] Плагінна формула з половинним парсингом теж повідомляє про залишок.

### 1.6 Поправки — це факти, а не речення (⚠ зміна формату `log.jsonl`)
- [ ] Стара строка логу (записана до 2026-09-04) **досі рендериться** — перевір, що старий лог не
      зламався.
- [ ] Нова поправка (перевага / перекид шкоди / перекид d20) після перемикання мови читається
      **іншою мовою** — речення складається на читанні, а не на записі.

### 1.7 Savage Attacker
- [ ] Перекидає **тільки кістки зброї** — Hex/Bless d6, що їдуть на тій самій частині, лишаються з
      тим, що випало (раніше перекидались разом).
- [ ] **Shift-клік (лоток)** тепер теж озброює перекид — раніше пропозиція зʼявлялась лише при
      звичайному тапі.
- [ ] Пропозиція **не зникає**, якщо перед нею покрутити перевагу на тому ж кидку (був баг: рядок
      підмінявся, і пропозиція тихо відвалювалась; гірше — перекид міг переписати рядок на диску
      **без** поправки переваги).
- [ ] Назва пропозиції читається українською.

### 1.8 Героїчне натхнення (нове)
- [ ] Увімкни **Inspiration** у контролах, зроби будь-який кидок з d20 → у Playbar і в лозі на
      цьому рядку зʼявляється золотий чип.
- [ ] **5.5e**: чип перекидає d20 і **лишається новий** результат (навіть якщо гірший) — це RAW.
      Пара кубів від переваги при цьому **зникає** (свідомо: «використай новий кидок» ≠ «візьми
      кращий з двох»).
- [ ] **5e**: той самий чип дає **перевагу** (доклацує другий кубик).
- [ ] Прапорець гасне після витрати, чип більше не пропонується, у лозі є поправка
      «Inspiration: 14 перекинуто → 4».

### 1.9 Назва кидка не замерзає мовою
- [ ] Зроби кидок **Удару без зброї** англійською → перемкни на українську → рядок логу читається
      «Удар без зброї».
- [ ] Те саме для волеї: «Удар без зброї 2/3».
- [ ] Назва **зброї/закляття** лишається як у контенті (дані не перекладаються) — це правильно.
- [ ] Маркери без кидка (короткий відпочинок, ритуальний каст) теж читаються обраною мовою.

## 2. Бій

### 2.1 Удар на 0 ХП = провал рятівного кидка (нове, RAW)
- [ ] Зведи ХП рівно до 0 (не більше максимуму за один удар — це миттєва смерть), потім вдар ще раз
      → **+1 провал** і тост.
- [ ] Біля поля шкоди на 0 ХП зʼявляється чекбокс **«Це був критичний удар»** → з ним **+2 провали**.
- [ ] Чекбокс сам гасне після удару; поза 0 ХП його немає взагалі.
- [ ] Третій провал → екран смерті (`death_saves`), пипки лишаються редагованими руками.

### 2.2 Умовні здібності (Persistent Rage тощо)
- [ ] Рядок недоступної опції **більше не `disabled`** — на нього можна навести й клацнути,
      підказка каже **чому** («недоступно» vs «недостатньо ресурсу» — різні тексти).
- [ ] Клік по заблокованому рядку показує ту саму відмову, що й раніше (виконавець не пускає).
- [ ] Увійди в бій персонажем, у якого є опція з вікном (варвар 15, Persistent Rage) → тост
      «… можна використати зараз». На **перше** відкриття аркуша тостів бути не має.
- [ ] Маркер типу дії читається словом («бонусна дія»), а не `bonus_action`.

### 2.3 Мітка «використано цього ходу» (нове)
- [ ] Персонажу з гранованим кидком (Sneak Attack) **у бою** зʼявляється чип **USED THIS TURN**.
- [ ] Клік → рядок тьмяніє; **Наступний хід** знімає мітку.
- [ ] Поза боєм чипа немає (замість нього звичний маркер «roll»).
- ⚠ Мітку ставить **гравець**, не додаток — переконайся, що звичайний кидок її НЕ вмикає.

### 2.4 Панель «Особливості» (нове)
- [ ] На бойовому аркуші є панель із класовими особливостями, расовими рисами, передісторією та
      рисами — окремими секціями, кожен рядок розкривається (`<details>`, працює з клавіатури).
- [ ] Показуються й ті особливості, що складаються **лише з тексту** (без ефект-токенів) — саме їх
      раніше не було ніде.

### 2.5 Провенанс на фокусі, а не лише на наведенні
- [ ] Пройдись **Tab**ом по КБ, рятівних, навичках, макс. ХП, DC закляття → спливає розбір
      («звідки число»), Escape закриває.
- [ ] Бонус атаки закляттям тепер теж має розбір (раніше не мав).
- [ ] Модифікатор навички пояснює себе **на числі** (раніше висів на кнопці, яка половину часу
      вимкнена).

- [ ] Панель **Інвентар** → під смугою навантаження пʼять монет (мм/см/ем/зм/пм) з полями вводу
      і рядок курсу під ними.
- [ ] Введи 100 зм → навантаження **не змінюється** (вага монет типово вимкнена).

- [ ] Увімкни вагу → 100 монет = **+2 фунти** у смузі навантаження.
- [ ] Сховай електрум → зникає зі стрічки, **значення зберігається** (покажи знову — на місці).
- [ ] Перезавантаж → і монети, і приховані номінали, і перемикач ваги на місці.

## 4. Ресурси та відновлення

### 4.1 Дві осі recharge (`{trigger, amount}`)
Старі слова на диску не змінились (`short`, `long`, `short_one`, `consumable`, `other`) — вони тепер
цукор. **Головне: перевірити, що відпочинки поводяться як раніше.**

- [ ] Короткий відпочинок: `short`-пул відновлюється **повністю**, `short_one` (Second Wind, Rage
      2024) — **на одне використання**, `long`-пул не чіпається.
- [ ] Тривалий відпочинок: відновлює все, крім `consumable` і `other`.
- [ ] Чип відновлення на панелі ефектів читається словом; для часткового — «короткий відпочинок (+1)».

### 4.2 Світанок / сутінки (нове)
- [ ] Персонажу з пулом, що відновлюється на світанку (зараз лише homebrew-рядок:
      `grant_resource:wand_charges:7:dawn(1d6+1)`), у смузі **PASS TIME** зʼявляється кнопка
      **Світанок**.
- [ ] Кнопки немає, якщо такого пулу нема — це навмисно.
- [ ] Тривалий відпочинок **не** відновлює dawn-пул (RAW привʼязаний до години).
- [ ] Натиснення «Світанок» кидає `1d6+1` і каже в тості, скільки повернулось.

## 5. Ефекти: бонус може називати ОДНУ річ (SCOPED-BONUS)

Нова граматика: `flat_bonus:damage.melee+2`, `damage.<id_зброї>`, `damage.<id_закляття>`.
Старе `flat_bonus:attack:ranged+2` (Archery) працює як раніше.

- [ ] Archery досі дає +2 лише дальнім (регресії немає).
- [ ] Homebrew-ефект `flat_bonus:damage.melee+2` → потрапляє тільки в ближній бій, у лук не йде.
- [ ] `flat_bonus:damage.greataxe+1` → тільки в цю зброю.
- [ ] `flat_bonus:damage.<spell_id>+3` → тільки в це закляття, інші не чіпає.
- [ ] Рятівні/навички **не** підхоплюють скоуплені бонуси.
- ⚠ Перевір, що бонус атаки **не подвоївся**: скоуп атаки складається один раз (у рядку атаки), не
      вдруге на кидку.

## 7. Пікери у білдері (a11y-переробка) — **шукати регресії тут**

Великий пікер (закляття 658 / речі 773) перероблений з `listbox` на `grid`. Пікселі не рухались
(0 px у `shot.mjs`), але поведінка клавіатури змінилась.

- [ ] Пошук + ↑/↓ рухають підсвітку, Enter читає, **другий Enter бере** — як раніше.
- [ ] **Tab** з поля пошуку веде в список: тепер це **2 зупинки** (галочка + тіло підсвіченого
      рядка) замість тисячі; далі — назовні.
- [ ] Заголовки секцій лишились власними зупинками (їх можна згорнути з клавіатури).
- [ ] Липкий заголовок секції досі «їде» при скролі.
- [ ] Згорнута секція **не ховає** збіг пошуку.
- [ ] Подвійний клік по рядку досі бере запис.
- [ ] Мовний пікер (той, що з пошуком у списку мов) працює як раніше.

## 8. Компендіум і авторинг

### 8.1 Нові типи в списку
- [ ] У списку типів зʼявились **Resource** і **Resource option** (12 і 14 рядків).
- [ ] Їх можна відкрити, створити нові, відредагувати, видалити — як будь-який інший тип.
- [ ] **Пошук/палітра (Ctrl+K) їх не показує** — навмисно, це не статті.

### 8.2 Збереження форми більше не падає на порожній клітинці
- [ ] Створи новий `resource_option`, заповни лише назву й `resource` → зберігається (раніше
      скаржився на порожній `action_type`).
- [ ] Дві однакові помилки валідації більше не кладуть сторінку (був `each_key_duplicate`).

### 8.3 Призначення типу файлу (тільки desktop)
- [ ] Settings ▸ Content health → рядок «не зрозуміло, що у файлі» має селект типу + кнопку
      **Assign type**; після натискання файл підхоплюється як цей тип.

### 8.4 Білдер апкаст-токенів (нове)
- [ ] Компендіум ▸ Spell ▸ Add/Editor → під полем `upcast` рядок **BUILD A RULE**: що росте / як /
      скільки → показує токен (`damage:per_slot(1d6)`) **до** додавання.
- [ ] «Додати» дописує токен у поле через `;`; поле лишається редагованим руками.
- [ ] Кнопка не активна, поки токен не читається парсером.

### 8.5 Редагування/видалення homebrew (перевірено, але варте ока)
- [ ] Правка **закляття** і **монстра** через звичайну форму (не було окремого редактора).
- [ ] Видалення homebrew-рядка з підтвердженням; «перетворити на чернетку» повертає його в Drafts.

## 9. Локалізація (≈30 комітів) — головна перевірка: **пройти все українською**

Усе UI читається з каталогів; **дані** (назви класів, зброї, ефектів, homebrew-школи) лишаються як у
контенті — це навмисно.

Пройди українською й шукай англійські залишки / зламану граматику:

- [ ] Бойовий аркуш: усі панелі, попапи (temp HP, level-up, add-effect, кастомний модифікатор,
      show/hide, закріплені чуття, апкаст, короткий відпочинок), екран смерті, дропдаун тривалості.
- [ ] Ролер і лоток: кнопка кидка, підказки пілюль, легенда, перевага/крит, «промах», «скинутий d20».
- [ ] Лог і Playbar, картка-тост (зокрема її **aria-label**: «Атлетика — 16. Закрити»).
- [ ] Компендіум: заголовки груп, фасети, деталі, кнопка **Filter**, режими редагування.
- [ ] Settings: усі вкладки, зокрема **перенесення теки даних** (усі помилки й діалоги).
- [ ] Спільні діалоги: підтвердження, попередження про чернетки (**перевір числівники: 1 / 2 / 5
      чернеток** — там три гілки множини), міграція даних.
- [ ] Форма homebrew: 18 підказок полів, помилка збереження, попередження про рівень > 9.
- [ ] Content health і проблеми деривації.
- [ ] Банер концентрації: «Рятівний провалено» і «{закляття} закінчується».
- [ ] Смуга **PASS TIME**: `+1 рд`, `+1 хв`, `+1 год`.
- ⚠ Типова помилка цієї хвилі — **іменник, вставлений у чужу рамку**. Якщо десь бачиш
      «Перевірка {СИЛ}» з неправильним відмінком — це і є баг, ключ треба цілою фразою.

## Де б я шукав баги першим ділом

1. **Лог після перезавантаження** — волея як блок, `modParts`, старі рядки з англійською прозою,
   поправки. Тут найбільше змін формату запису.
2. **Натхнення в 5e** — гілка з перевагою тестувалась менше, ніж 5.5e-перекид.
3. **Скоуплені бонуси** — чи не подвоївся бонус атаки, чи не поїхав Rage (він досі широкий
   `flat_bonus:damage+2`, RAW-звуження свідомо не робив: RAW каже «сила», а аркуш не знає, якою
   характеристикою бив).
4. **Пікер закляттів з клавіатури** — roving tabindex найлегше зламати скролом і згортанням секцій.
5. **Вага монет** — чи не заганяє в «понад місткість» когось, хто просто ввів золото.
6. **0 ХП** — послідовність «удар → провал → третій провал → екран смерті» і те, що чекбокс криту
   не залипає.
